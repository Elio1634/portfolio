📌 Présentation

Dans le cadre de ma formation, nous avons dû créer, présenter et réaliser un scénario d'attaque. Pour seule consigne, nous devions utiliser le matériel et les ISO fournis par l'établissement :

- Windows Server 2008, 2012, 2016, 2019, 2022
- Debian
- Stormshield
- Windows 7, 10, 11
- Splunk
- Kali

Lors de la présentation, nous devons fournir : le Contexte, le Plan d'adressage, un Schéma de l'infrastructure et une partie défense.

📌 Contexte

Bit à Part est une PME de 150 employés, spécialisée dans les solutions informatiques pour les collectivités territoriales. L’attaquant profite du manque de sensibilisation des utilisateurs afin de récupérer leurs accès.

Un mail frauduleux redirige l’utilisateur vers une fausse page Web contenant un virus. L’utilisateur saisit ses identifiants Active Directory, ce qui permet à l’attaquant de récupérer son mot de passe.

Une fois sur le poste, l’attaquant installe un script (.bat), réalise une escalade de privilèges, installe un keylogger, récupère les identifiants administrateurs, pivote vers les serveurs, puis finit par bloquer l’entreprise en supprimant l’AD.

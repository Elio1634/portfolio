📌 Contexte

Un concurrent veut détruire des informations techniques d’une entreprise concurrente pour obtenir un avantage concurrentiel. Compromissions d’un individu pour obtenir des informations essentielles pour l’intrusion dans le système d’information de l’entreprise.

Le salarié de l’entreprise donne ses codes d’accès + IP du VPN. Le concurrent exploite l'accès VPN et l’accès au compte, pour commencer une campagne de phishing interne, dans le but d’obtenir une élévation de privilèges. Comme les comptes Active Directory sont reliés à Office 365, cela donne un accès à la messagerie professionnelle du salarié.Envoi un faux mail à partir de la session de l’employé corrompu. Par un mouvement latéral d’obtention de code d’accès de personnes avec des droits supérieur.

Recherche des serveurs de sauvegarde présents.Pour détruire facilement les sauvegarde, il tente d’obtenir un ticket Kerberos : Attaque Golden Ticket via l’Active Directory. Une fois les points de sauvegarde et les données identifiés. Création de fausses données sur la même topologie de l’arborescence existante, avec des données quelconques de même volume.Maintenant, l’attaquant peut effectuer la suppression des données dans les serveurs par le lancement d’un script.Une fois, son objectif terminé l’attaquant va effacer ses traces.

Avec l’obtention de son accès avec des droits illimités sur l’active directory, la suppression des journaux par un script et une GPO, permet d’effacer les événements précédents.
